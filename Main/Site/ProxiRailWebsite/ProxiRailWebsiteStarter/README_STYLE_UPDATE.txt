PROXIRAIL RAILROAD STYLE UPDATE

This changes the website from the generic blue dashboard look to a more
distinct railroad-crossing visual identity.

DESIGN CHANGES
- Archivo Black headings
- Work Sans body text
- Black, warning yellow, warm off-white, and restrained red
- No blue gradient
- No rounded pill-heavy dashboard look
- Sharper cards, offset shadows, industrial labels, and crossing stripes
- More direct prototype wording

INSTALL

1. Stop Flask with Ctrl+C.

2. Extract this ZIP into:

   C:\Users\isense\Documents\ProxiRailWebsite\ProxiRailWebsiteStarter

3. Replace the existing files when Windows asks:
   templates\index.html
   templates\intersection.html
   static\styles.css

4. Restart:

   python app.py

5. Refresh the browser with Ctrl+R.

The Google Fonts load from the internet. The CSS includes local fallback fonts
in case the font service is unavailable.
