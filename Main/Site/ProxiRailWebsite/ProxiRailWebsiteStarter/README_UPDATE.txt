PROXIRAIL PROFESSIONAL TYPOGRAPHY UPDATE

This update keeps the current train, person, camera, hold-button, charts, and
presentation features while changing the typography to look more restrained and
professional.

Changes:
- IBM Plex Sans replaces Archivo Black and Work Sans
- Smaller title and heading sizes
- Natural sentence case instead of all-capital headings
- Less letter spacing
- Medium weights instead of extra-heavy display text
- Risk alerts and the PET acronym remain clear

Install:
1. Stop Flask with Ctrl+C.
2. Extract this ZIP into:
   C:\Users\isense\Documents\ProxiRailWebsite\ProxiRailWebsiteStarter
3. Replace:
   templates\index.html
   templates\intersection.html
   static\styles.css
   static\app.js
4. Restart:
   python app.py
5. Refresh:
   Ctrl+R
