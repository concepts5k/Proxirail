PROXIRAIL WEBSITE STARTER

1. Extract this ZIP into:
   C:\Users\isense\Documents\ProxiRailWebsite

2. Open PowerShell in that folder.

3. Create the environment:
   python -m venv .venv

4. Activate it:
   .\.venv\Scripts\Activate.ps1

5. Install Flask:
   pip install -r requirements.txt

6. Start the website:
   python app.py

7. Open:
   http://127.0.0.1:5000

The sample PET, risk, distance, and conflict values are demonstration data.
Edit data\intersections.json later when real team results are ready.
